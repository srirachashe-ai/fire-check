# ระบบตรวจสอบถังดับเพลิงประจำเดือน (เวอร์ชัน GitHub Pages + Firebase)

หน้าเว็บนี้เปิดผ่าน GitHub Pages และเก็บข้อมูลผลตรวจ รูปยืนยัน และทะเบียนถังไว้ใน Firebase
ทำตาม 3 ส่วนด้านล่างตามลำดับ ใช้เวลารวมประมาณ 20–30 นาที

ไฟล์ในชุดนี้:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `firebase-shim.js` | ตัวเชื่อมหน้าเว็บกับ Firebase (ไม่ต้องแก้) |
| `firebase-config.js` | ค่าตั้งค่า Firebase ของคุณ (**ต้องแก้** ในส่วนที่ 1) |
| `seed.json` | ข้อมูลตั้งต้น: ถัง 139 ใบ และรายชื่อพนักงาน 108 คน |
| `firestore.rules` | กฎสิทธิ์ของฐานข้อมูล (คัดลอกไปวางในส่วนที่ 1) |

---

## ส่วนที่ 1: ตั้งค่า Firebase (ฐานข้อมูล)

1. เข้า https://console.firebase.google.com แล้วเข้าสู่ระบบด้วยบัญชี Google
2. กด **สร้างโปรเจ็กต์ (Create a project)** ตั้งชื่อ เช่น `fire-extinguisher-check` ปิด Google Analytics ได้ แล้วกดสร้าง
3. **เปิดฐานข้อมูล:** เมนูซ้าย **Build > Firestore Database > Create database**
   - เลือกตำแหน่ง `asia-southeast1 (Singapore)` (ใกล้ไทยที่สุด เปลี่ยนภายหลังไม่ได้)
   - เลือก **Start in production mode**
4. **วางกฎสิทธิ์:** ในหน้า Firestore ไปแท็บ **Rules** ลบของเดิมทั้งหมด วางเนื้อหาจากไฟล์ `firestore.rules` แล้วกด **Publish**
5. **เปิดการเข้าสู่ระบบอัตโนมัติ:** เมนูซ้าย **Build > Authentication > Get started** แท็บ **Sign-in method** เลือก **Anonymous** แล้วกด **Enable > Save**
6. **เอาค่าตั้งค่ามาใส่:** กดรูปเฟือง **Project settings** เลื่อนลงถึง **Your apps** กดไอคอน **`</>`** (Web) ตั้งชื่อแอป แล้วกด Register
   - Firebase จะแสดงโค้ดที่มี `const firebaseConfig = { apiKey: "...", ... }`
   - เปิดไฟล์ `firebase-config.js` แล้วแทนค่าที่เขียนว่า "ใส่ค่า ..." ทั้ง 6 บรรทัดด้วยค่าจริงจาก Firebase (คัดลอกเฉพาะค่าในเครื่องหมายคำพูด)

## ส่วนที่ 2: สมัคร GitHub และเผยแพร่หน้าเว็บ

1. สมัครบัญชีที่ https://github.com/signup (ชื่อบัญชีจะเป็นส่วนหนึ่งของลิงก์เว็บ เช่น `srf-safety`)
2. มุมขวาบนกด **+ > New repository**
   - Repository name เช่น `fire-check`
   - เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
   - กด **Create repository**
3. ในหน้า repository ที่สร้าง กดลิงก์ **uploading an existing file** (หรือ **Add file > Upload files**)
   - ลากไฟล์ทั้งหมดในชุดนี้ลงไป (รวม `firebase-config.js` ที่แก้แล้ว) แล้วกด **Commit changes**
4. ไปที่ **Settings > Pages**
   - Source เลือก **Deploy from a branch**
   - Branch เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอ 1–2 นาที หน้าเดียวกันจะแสดงลิงก์เว็บ เช่น `https://srf-safety.github.io/fire-check/`
6. กลับไป Firebase: **Authentication > Settings > Authorized domains > Add domain** ใส่ `srf-safety.github.io` (ชื่อบัญชีของคุณ)

## ส่วนที่ 3: เปิดใช้งานครั้งแรก

1. เปิดลิงก์เว็บ ครั้งแรกระบบจะนำเข้าถัง 139 ใบ และรายชื่อพนักงานให้อัตโนมัติ (รอสักครู่)
2. **ตั้งรหัสผ่านหลังบ้านทันที:** กด **หลังบ้าน > ตั้งค่า > รหัสผ่านหลังบ้าน**
   ก่อนตั้งรหัส ทุกคนที่เปิดเว็บเข้าหลังบ้านได้
3. ไป **หลังบ้าน > คิวอาร์โค้ด** กด **PDF ป้ายทั้งหมด** แล้วพิมพ์ป้ายติดถัง
   QR จะใช้ลิงก์ GitHub ของคุณให้อัตโนมัติ
4. ส่งลิงก์เว็บให้พนักงาน แนะนำให้ "เพิ่มไปยังหน้าจอหลัก" ในมือถือ

## ข้อควรรู้

- **สิทธิ์การใช้งาน:** ทุกคนที่มีลิงก์บันทึกผลตรวจได้โดยไม่ต้องสมัครบัญชี หลังบ้านป้องกันด้วยรหัสผ่าน
  รหัสผ่านนี้ใช้กันพนักงานทั่วไปไม่ให้เข้าหลังบ้าน แต่ไม่ใช่ระบบความปลอดภัยระดับสูง ไม่ควรเผยแพร่ลิงก์นอกโรงงาน
- **ค่าใช้จ่าย:** Firebase แผนฟรี (Spark) ให้อ่านข้อมูล 50,000 ครั้งและเขียน 20,000 ครั้งต่อวัน ซึ่งเกินพอสำหรับถัง 139 ใบ
  รูปเก็บในฐานข้อมูลและย่อให้ประมาณ 100–250 KB ต่อรูป พื้นที่ฟรีของฐานข้อมูลจะพอใช้ราว 2–3 ปี
  แนะนำให้ส่งออก Excel ทุกเดือนเก็บไว้ และตรวจปริมาณการใช้ที่ Firebase console เป็นระยะ
- **ต้องมีอินเทอร์เน็ต** ระหว่างตรวจและส่งผล
- **แก้หน้าเว็บภายหลัง:** อัปโหลดไฟล์ `index.html` ใหม่ทับไฟล์เดิมใน repository ข้อมูลใน Firebase ไม่หาย
- **`firebase-config.js` ไม่ใช่รหัสลับ** Firebase ออกแบบให้ค่านี้เปิดเผยได้ ความปลอดภัยของข้อมูลมาจากกฎใน `firestore.rules`
